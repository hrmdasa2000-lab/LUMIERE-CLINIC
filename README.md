# LUMIÈRE Clinic — Aesthetic & Skincare Website

وب‌سایت دوزبانه (فارسی RTL / انگلیسی LTR) **کلینیک زیبایی لومیر (LUMIÈRE Clinic)**؛ طراحی‌شده با ساختار سبک، واکنش‌گرا و بهینه برای انتشار روی GitHub Pages.

## ساختار فایل‌ها
- `index.html`: صفحه اصلی کلینیک
- `pages/`: صفحات داخلی (`about.html`, `services.html`, `service-detail.html`, `doctors.html`, `gallery.html`, `blog.html`, `booking.html`, `contact.html`)
- `css/style.css`: شیوه‌نامه اختصاصی و اتصال به فونت محلی `IRANSansMobile`
- `js/app.js`: مدیریت تغییر زبان RTL/LTR، فیلتر خدمات، گالری و اعتبارسنجی فرم‌ها
- `assets/images/`: تصاویر محلی WebP و JPG
- `assets/fonts/`: فایل‌های فونت فارسی `IRANSansMobile.*`
